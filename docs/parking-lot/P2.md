## The question

What a GitWrite server is for once the local-first plugin (D8, D9) works, and how it's built. Candidate jobs from the Veneer brief's step 7: a sync target, collecting a beta reader's feedback, and export through pandoc (with a download route that returns bytes, since the old export endpoints returned server-side paths).

## Thread

> Append-only. Each grill round that touches this thread adds a dated section below the existing ones.

### 2026-10-24 — opened

Asked in round 2 while the plan was still server-first (D3). The recommendations, all unanswered because D8 (local first) superseded the premise before they were settled:

- **Auth (was Q8):** long-lived API tokens, one per Veneer install, stored hashed in a small file or SQLite. `gitwrite token create <label>` / `token revoke`. Each token belongs to the owner identity, so multi-user later means adding identities (D2).
- **Repo mapping (was Q9):** `POST /repos` returns a server-generated ID; Veneer stores it in project settings. One validated resolver maps the ID to a path under a single `REPOS_ROOT` and rejects anything else. That's the fix for the audit's path problems.
- **Concurrent saves (was Q10):** each write sends the commit it expects as the branch head; the server updates the ref compare-and-swap and returns `409 Conflict` with the current head otherwise.
- **Deployment (was Q11):** one Docker image, repos on a mounted volume, HTTP inside the container, TLS from a reverse proxy (Caddy or whatever is already running). No Postgres, Redis or nginx.

Facts to carry forward:

- Veneer's `api.net.fetch` blocks localhost and LAN addresses until the writer allows the address in Settings > Plugins > <plugin> > Local addresses.
- There's no host list in the manifest; the writer is asked once per address.
- Cookie and Host headers are dropped, there's a 30 s timeout, and text answers are cut at 5 MB.
- The token belongs in `api.secrets`.
- The old `gitwrite_api` is deleted in queue 1 (D11), so this starts from scratch. Read [docs/AUDIT.md](../AUDIT.md)'s security section before designing it.

Parked because v1 has no server.
